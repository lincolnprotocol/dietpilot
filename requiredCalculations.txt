For males:
BMR = 10 × weight(kg) + 6.25 × height (cm) −5 × age (years) + 5

For females:
BMR = 10 × weight (kg)+ 6.25 × height (cm) −5 × age (years) − 161

Exercise multiplier:
| Activity Level                                  | Multiplier |
| ----------------------------------------------- | ---------: |
| Sedentary (little/no exercise)                  |        1.2 |
| Lightly active (1–3 days/week)                  |      1.375 |
| Moderately active (3–5 days/week)               |       1.55 |
| Very active (6–7 days/week)                     |      1.725 |
| Extra active (physical job or intense training) |        1.9 |

Add the option in the input profile to specify the exercise frequency
with the specification of what the activity level means. For Sedentary (little / no exercise)
to Very active (6-7 days / week) to Extra active (physical job or intense training)
